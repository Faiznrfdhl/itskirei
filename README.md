## 📖 About

ItsKirei is a web-based AI image enhancement platform that helps users improve image quality through artificial intelligence.

Users can upload low-resolution images and transform them into higher-quality images with improved details and clarity.

The name **Kirei (きれい)** comes from Japanese, meaning *beautiful, clean, and refined*, representing the goal of this project: making every image look better.
